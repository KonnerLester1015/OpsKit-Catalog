# Fonts

Served from this site so pages make no third-party requests. Both are variable fonts (one file covers
every weight), subset to Latin and Latin Extended as Google Fonts ships them.

| Font | Used for | Files | Licence |
| --- | --- | --- | --- |
| Archivo | headings, UI, body | `archivo-latin.woff2`, `archivo-latin-ext.woff2` | SIL OFL 1.1 |
| JetBrains Mono | ids, versions, labels, code | `jetbrains-mono-latin.woff2`, `jetbrains-mono-latin-ext.woff2` | SIL OFL 1.1 |

The licence text is in [OFL.txt](OFL.txt). The `@font-face` rules are at the top of `assets/css/site.css`.
