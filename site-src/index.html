New to OpsKit?

This catalog fills OpsKit. OpsKit runs the scripts.

An extensible PowerShell toolkit for system administrators. Automate everyday tasks, manage infrastructure, and connect the tools you already use, from one clean terminal menu.

  • Interactive menus

    Arrow keys, type-to-filter search, breadcrumbs, recent scripts.

  • Home screen dashboard

    Widgets for local health, your domain controller or Entra roles.

  • Drop-in scripts

    Put a .ps1 in a folder and it appears in the menu.

  • Dependency checks

    Required modules are checked before a script runs.

Get OpsKit

v0.1.0 · MIT licensed · on GitHub

You need

  • PowerShell 7.4+ winget install Microsoft.PowerShell
  • PwshSpectreConsole 2.3+ (offered on first run)
  • A UTF-8 terminal. Windows Terminal is recommended.

Quick start

> git clone {{OPSKIT_URL}}.git
> cd OpsKit
> pwsh ./OpsKit.ps1
